# ♡왕전초 길찾기왕!♡ (Wangjeon Numberlink King)

같은 색 두 점을 이어 **판의 모든 칸을 빈칸 없이** 채우는 점잇기(넘버링크 / Flow Free) 퍼즐입니다.
`♡왕전초 연산왕!♡`·`♡왕전초 타이머왕!♡`·`♡왕전초 눈치왕!♡`·`♡왕전초 점프왕!♡`와 같은 왕전초 시리즈예요.

**바로 플레이:** https://chohanui2-home.github.io/wangjeon-connect/

## 게임 규칙

- 같은 색 **두 점**을 손가락으로 이어요. 위·아래·왼쪽·오른쪽으로만 한 칸씩 움직입니다.
- **다른 색 선이나 다른 색 점 위로는 지나갈 수 없어요.** 지나가려 하면 `다른 색 선과 겹칠 수 없어요!` 하고 알려 줍니다.
- 자기 색 선 위로 되돌아가면 그 지점까지 **되감기**고, 한 색의 점을 새로 누르면 그 색 선을 처음부터 다시 그릴 수 있어요.
- **색을 다 이어도 빈칸이 하나라도 남으면 아직 완성이 아니에요.** 판의 모든 칸을 채워야 클리어!
  빈칸이 남으면 `색은 다 이었는데 빈칸 N칸이 남았어요! 빈칸 없이 채워 주세요` 하고 알려 주고, 남은 칸이 노랗게 깜빡입니다.
- 완성하면 경쾌한 효과음과 함께 **0.5초 뒤 다음 문제로 자동으로 넘어가요.** (마지막 문제면 다음 단계 1번)

## 5단계 × 4문제 = 20문제

| 단계 | 판 | 색 | 문제 |
|---|---|---|---|
| 1단계 | 3×4 | 3색 | 4 |
| 2단계 | 4×5 | 4색 | 4 |
| 3단계 | 5×6 | 5색 | 4 |
| 4단계 | 6×7 | 5~6색 | 4 |
| 5단계 | 7×8 | 6~7색 | 4 |

- 위쪽 `1단계 3×4` ~ `5단계 7×8` 탭으로 단계를, 그 아래 `◀`·`1 2 3 4`·`▶`로 문제를 **자유롭게** 오갑니다. 순서대로 다 깨지 않아도 돼요.
- 이미 푼 문제 번호에는 ✓ 가 붙습니다(화면에만 표시).
- `되돌리기` — 직전 동작(한 번의 선 긋기)을 되돌립니다.
- `처음부터` — 지금 판을 모두 지웁니다. (이것도 되돌릴 수 있어요)
- `힌트 보기` — 아직 못 이은 한 색의 정답 길을 그려 주고, 그 길과 겹치던 다른 색 선은 지웁니다.

## 공용 태블릿에서 쓰기

교실 태블릿에 그대로 올려 두고 쓰도록 **아무것도 저장하지 않습니다.** `localStorage`·쿠키를 전혀 쓰지 않아서,
문제나 단계를 옮기면 **항상 빈 판**으로 시작하고, 창을 새로 열면 ✓ 표시도 사라집니다.

## 특징

- **20문제 모두 실제 정답 경로를 생성·검증** — `gen_puzzles.py`가 판 전체를 색깔별 길로 **완전히 나눈 뒤** 두 점만 남겨 문제를 만듭니다. 그래서 20문제 전부 *겹침 0건 · 빈칸 0개* 정답이 수학적으로 보장됩니다.
- **단계가 올라가면 길이 꼬불꼬불** — 문제마다 색 길이 꺾이는 횟수를 세어 1단계 4회 → 5단계 22~30회로 난이도를 올렸고, 한 색이 판을 다 먹지 않도록 길이 균형(평균의 1.7배 이내)을 맞췄습니다.
- **같은 모양 도배 없음** — 단계 안에서 회전·반사·색 이름을 바꿔도 같은 판이 나오지 않도록 3칸 이상 다르게 만들었습니다.
- **민트·크림 스킨** — 연산왕(파랑)·눈치왕(코랄)·점프왕(라벤더)과 겹치지 않는 산뜻한 민트/크림 바탕에, 점과 선은 선명한 원색 7색(빨강 #e5332e · 파랑 #2a6fd6 · 노랑 #f0b400 · 초록 #12a05c · 분홍 #e7559f · 보라 #7c4be0 · 주황 #ef7a18)으로 구분합니다. 글자 테두리(`-webkit-text-stroke`)는 어디에도 쓰지 않았습니다.
- **손가락에 붙는 그리기** — 빠르게 끌어도 사이 칸을 채워 주고, 지나온 길로 돌아가면 되감기고, 다른 색에 닿으면 그 자리에서 막힙니다.
- **소리** — Web Audio로 만드는 효과음(선 잇기·색 완성·클리어 팡파레·겹침), `🔊 소리`로 끌 수 있습니다. 음원 파일은 없습니다.
- **앱처럼 설치** — 홈 화면에 추가하면 전체화면 앱처럼 열립니다. 외부 CDN·폰트·이미지 요청 0건.

## 파일

- `index.html` — 게임 전체가 들어 있는 **단일 파일**(외부 요청 0건). 파일 하나만 보내도 그대로 열립니다.
- `app_template.html` — 빌드용 템플릿(`__PUZZLES__` 자리표시자)
- `gen_puzzles.py` — 20문제 생성·검증 스크립트 (`puzzles.json` 작성)
- `puzzles.json` — 문제 데이터(점·정답 경로)
- `build.py` — 문제 주입 + 단일 파일 규칙 검사 후 `index.html` 생성
- `test_app.py` — 정적 규칙 + 20문제 전수 수학 검증 + QuickJS로 실제 스크립트 실행 검사

## 다시 빌드하기

```bash
python3 gen_puzzles.py --write   # 문제 다시 만들기 (--show 로 판 미리보기)
python3 build.py                 # index.html 생성 (단일 파일 검사 포함)
python3 test_app.py              # 테스트 (quickjs 파이썬 모듈 필요)
```

`build.py`는 같은 바이트를 `dashboards/왕전초-길찾기왕.html`에도 써서, 오프라인 사본과 배포본이 갈라지지 않게 합니다.
